# X

Read [Quickstart](docs/quickstart.md) and [How approvals work](docs/safety_model.md) before using an account. Start with the local check. Ask before making live calls that use X credits.

Use `x-api-tool api ops list` to find the right X command. Work out the operation and targets from the request and the list. Ask only for information you cannot verify. Keep tokens and .env contents out of chat and logs.

Before posting, replying, deleting a post or sending a message, show the connected account and exact change in a saved plan. Apply the approved plan from the same account. Read the result, including any refusal. If X did not confirm the change, check before repeating it.

For direct messages, follow the consent and opt-out rules in [How approvals work](docs/safety_model.md) and use the message commands in [Commands](docs/command_reference.md).
