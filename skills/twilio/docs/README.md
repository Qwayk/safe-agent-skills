## Choose by what you need

- **I want to know what to ask.** Start with [real Twilio use cases](use_cases.md).
- **I need exact CLI syntax.** Use the [command reference](command_reference.md).
- **I want to understand approvals.** Read the [safety model](safety_model.md).
- **I need help with keys, OAuth, regions, or edges.** See [authentication](authentication.md) and [configuration](configuration.md).
- **I want to check what is actually covered.** Use the generated [API coverage ledger](api_coverage.md).
- **I need to understand the audited write fields and safe subsets.** Use the [command reference](command_reference.md) and inspect the exact command locally.
- **I want to know what was tested.** Read [proof and unverified behavior](proof.md).
- **The command failed.** Try [troubleshooting](troubleshooting.md).
- **I am connecting an agent.** Read [how the skill wrapper should behave](skills_wrappers.md).
