# What to ask your agent

- **Choose a model.** “List the Gemini models I can use. Which would you try for this document and why?”
- **Check prompt size.** “Count the tokens in `request.json` and tell me how much room I have left for the answer.”
- **Run a prompt or make embeddings.** “Show me the model, request and expected cost before you send it.”
- **Check a batch or file search store.** “Find this batch and tell me whether it finished.” “Show me the documents in this store.”
- **Prepare a change.** “Show me what you would upload or delete. Include the exact file or resource and tell me if I can undo it.”
