# What you can do with Salesforce

Start with a question you can check against a few records.

## Accounts, contacts, and opportunities

- “Which opportunities changed stage this week?”
- “Show me accounts that are missing fields we need for an import.”
- “Run this SOQL query and explain what the records show.”

## Fields, rules, and layouts

- “Describe the Account object and explain the fields we use most.”
- “Check the list views and layouts for this object.”
- “Show the approval rules and tell me which ones affect this process.”

## Bulk jobs and grouped changes

- “Check this bulk job and show me which rows failed.”
- “Prepare a query for the export and show me what it will read.”
- “Show me the plan for this grouped change and the records and options it would use.”

Ask the agent to name the Salesforce org and explain which records or job it checked. For changes, review [the approval steps](safety_model.md) first.
