# Concepts

These are the small words that matter most when you ask an agent to work inside WordPress.

- **Dry-run**: the default mode. It shows what would change without touching the site.
- **Apply**: add `--apply` only after you have reviewed the plan and want the command to make the change.
- **Verify**: after applying, the tool re-fetches the target and checks that the new values match.
- **Caption policy**: a Media Library caption is different from visible caption text inside a post. Ask the agent which one it is changing before approving a caption job.

Good first ask: "Show me the dry-run plan for this WordPress edit, name the exact post or media item, and stop before apply."
