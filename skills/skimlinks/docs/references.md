# Skimlinks reference guides

The original build used the Skimlinks developer center on June 8, 2026. On November 23, 2026, we checked the current Merchant, Reporting, Product Key, and Link Wrapper definitions for the local fixes.

| What you need | Skimlinks documentation |
| --- | --- |
| Find merchants, domains, categories, and offers | [Merchant API](https://developers.skimlinks.com/merchant.html) · [OpenAPI definition](https://developers.skimlinks.com/openapi/merchants-api.yaml) |
| Check commissions and performance | [Reporting API](https://developers.skimlinks.com/reporting.html) · [OpenAPI definition](https://developers.skimlinks.com/openapi/reporting-api.yaml) |
| Look up products and alternatives | [Product Key](https://developers.skimlinks.com/product-key.html) · [OpenAPI definition](https://developers.skimlinks.com/openapi/products-api.yaml) |
| Build an affiliate link | [Link Wrapper](https://developers.skimlinks.com/link.html) · [OpenAPI definition](https://developers.skimlinks.com/openapi/waypoint.yaml) |
| Set up Skimlinks exports | [Data Pipe](https://developers.skimlinks.com/data-pipe.html) |
| Add Skimlinks to a site | [Skimlinks JavaScript](https://developers.skimlinks.com/skimlinks-script.html) |

The [API coverage guide](api_coverage.md) shows which operations the CLI provides. Merchant v4 is the current API used by the tool. Product Key may need separate access, and both lookups need a publisher domain ID. Data Pipe and site JavaScript have their own setup.
