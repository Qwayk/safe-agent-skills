# What you can do with HubSpot

Start with a question you can check against a few real records.

## Contacts, companies, deals, and tickets

- “Find contacts with no owner and give me their IDs.”
- “Find companies in this industry and show me their contacts.”
- “Show the open deals in this stage and tell me which fields are missing.”
- “Find support tickets that match these rules before we follow up.”

## Fields, pipelines, and links between records

- “Show the fields we can use on deals and tell me which ones HubSpot requires.”
- “Show how these contacts are linked to companies and deals.”
- “Explain what each stage of this pipeline means.”
- “Check whether this account supports the custom record type we need.”

## Imports, exports, and changes

- “Preview this import. Show me the files, how the columns map to HubSpot fields, and any issues you can check locally.”
- “Check whether import 123 finished, and explain any errors.”
- “Prepare an export of the records we reviewed, then ask for my approval to start it.”
- “Show me the plan to update these contacts before I approve it.”
