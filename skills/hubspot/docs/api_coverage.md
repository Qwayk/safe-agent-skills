# HubSpot API coverage

This table shows which HubSpot CRM endpoints the CLI calls, what each command does, and which approvals it needs. All commands start with `qwayk-hubspot-safe-agent-cli`.

Most routes are pinned to `2026-03`. The GDPR deletion route uses `2025-09`. The original endpoint audit was June 4, 2026 UTC. See [HubSpot’s version guide](https://developers.hubspot.com/blog/date-based-api-versioning-migration-playbook) and [the source list](references.md).

Access depends on your account plan, record types, and token permissions. Owners are read-only. Schemas here are for custom record types. Import creation uploads local files. Completed export links can expire after five minutes.

Write previews run locally. All live writes need `--apply --ack-no-snapshot` after approval. The table shows any extra flags. [How to review a change](safety_model.md)
