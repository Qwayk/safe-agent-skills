# References

These are the official Statuspage sources used to keep the tool grounded. Use them when you need to confirm whether the public status API can answer a question about incidents, maintenance, components, or page-level status.

Last verified (UTC): 2026-01-26

## Statuspage

- Docs home (Manage API + general): https://developer.statuspage.io/
- Status API overview (page-level API): https://support.atlassian.com/statuspage/docs/what-are-the-different-apis-under-statuspage/
- Status embed (“uses the Status API”): https://support.atlassian.com/statuspage/docs/build-your-own-status-embed/

Normal users do not need an API key for the public status-page checks. Start with the public status page URL, then ask the agent to show current incidents, planned maintenance, or component status.
