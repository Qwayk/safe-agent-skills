# Statuspage docs

- [Quickstart](quickstart.md) gets you from a clean install to one useful page check.
- [Setup and common errors](onboarding.md) explains how to save the page you check often and what to do when a request fails.
- [Command guide](command_reference.md) shows which command to use for a current check or recent history.
- [Safety and output](safety_model.md) explains what the tool reads and how to tell a failed request from a reported outage.
- [API coverage](api_coverage.md) lists the four routes and their tests. [Atlassian references](references.md) link to the official docs.
- [Test results](proof.md) records what was checked. [Saved examples](examples/README.md) show the JSON the commands use and return.
