# What you can do with Amazon Creators

- **Find products.** Ask, "Find office headphones in the US and give me the Amazon links." Ask for the next page when you need more results.
- **Compare book formats.** Ask, "Look up these Amazon item IDs and show the binding, edition details, and related items." Amazon's catalog can help you shortlist books. Check Amazon or Audible before saying a book has no audiobook.
- **Compare variations.** Ask, "Which versions does Amazon show for this parent product?" The answer should say which marketplace the tool checked and what Amazon returned.
- **Find a category.** Ask, "Show the category path and children for this browse node." A browse node is Amazon's ID for a category in its catalog.

Your agent should preview the request, wait for approval, and report the results and any missing items or errors. See [Quickstart](quickstart.md).
