# Spaceship tool guides

Choose the page that matches what you need now.

If this is your first time, use [onboarding](onboarding.md) to add the API key and secret without putting them in chat. Then follow the [quickstart](quickstart.md) to list domains without changing the account.

If you want to know what to ask your agent, see [use cases](use_cases.md). If you are reviewing a possible live change, read the [safety model](safety_model.md) before approving it.

For exact commands and coverage, use the [command reference](command_reference.md) and [API coverage ledger](api_coverage.md). The [proof page](proof.md) says what was tested from source and packages, and what remains unverified without a live Spaceship account.

Maintainers can use the [wrapper guide](skills_wrappers.md), [references](references.md), [architecture](architecture.md), and [engineering notes](engineering_notes.md).
