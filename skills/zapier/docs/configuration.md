# Configuration

## Required files

- `.env.example` (template)
- `.env` (local secrets)

## Environment variables

- `ZAPIER_BASE_URL` (default: `https://api.zapier.com`)
- `ZAPIER_AI_ACTIONS_BASE_URL` (default: https://actions.zapier.com)
- `ZAPIER_TRIGGER_INBOX_BASE_URL` (default: https://api.zapier.com)
- `ZAPIER_ACCESS_TOKEN`
- `ZAPIER_CLIENT_ID`
- `ZAPIER_CLIENT_SECRET`
- `ZAPIER_JWT`
- `ZAPIER_TIMEOUT_S`

OS environment overrides `.env` values.
