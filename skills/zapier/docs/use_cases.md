# Use cases

Ask the agent clear jobs the tool can do well:

- "Show what Zaps and apps are available for this account, then rank anything that needs cleanup."
- "Pull one inbox and report new unprocessed messages."
- "Prepare a plan to update AI Actions or Zap templates, then wait for approval."

When a request is safe and read-only, the tool should answer directly. When it is a change, it should return a plan first.
