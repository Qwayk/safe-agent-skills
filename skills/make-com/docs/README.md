# Make.com API docs

This folder is the practical docs index for the Make.com safe CLI.

## Read in order

1. `quickstart.md` — run this first and get one outcome in minutes.
2. `onboarding.md` — configure `.env` and credentials.
3. `command_reference.md` — exact command options and patterns.
4. `safety_model.md` — write safety and approval gates.
5. `api_coverage.md` — official operation coverage and what is included.
6. `proof.md` — what was verified and what was not.
