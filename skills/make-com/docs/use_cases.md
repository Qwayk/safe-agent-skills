# Use cases

These are common real requests for this skill.

## Operations review

- "Show all active scenarios for team 42."
- "List recent audit-log entries for users and teams."
- "List all scenario folders and hook status for one organization."

## Access and control checks

- "Which users and roles exist in team 12?"
- "Find API tokens for the organization and show expiry risk."
- "Compare notification settings for a user before changing team rules."

## Safe change planning

- "Build a plan to deactivate scenario X after business hours."
- "Prepare a plan to revoke one organization API key only after a human review."
- "Review and compare scenario blueprint updates before applying."

## Support operations

- "Find incomplete executions and show most recent errors."
- "Check data store entries and devices/incoming-outgoing webhook history before changes."
- "List templates and SDK app status for migration planning."

All of these should start with read commands first, then explicit write planning.
