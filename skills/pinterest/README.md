# Pinterest

Read boards, sections, and pins, or save a copy of the account’s inventory. You can also read analytics, ads, and catalogs when your account has access.

```bash
npx skills add Qwayk/safe-agent-skills@pinterest -g -y
```

Start with a small read. Ask the agent to show the signed-in account, list one board, and list a few pins from it. [Connect your account](docs/onboarding.md) · [Quickstart](docs/quickstart.md)

To change a board or pin, save the preview for the signed-in account and review the details before approving it. The tool checks the saved plan and reads back the result. [Approval and recovery](docs/safety_model.md) · [All commands](docs/command_reference.md)
