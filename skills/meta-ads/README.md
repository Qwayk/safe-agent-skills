# Meta Ads

Check what your Meta ads spent, which campaigns changed, and which ads are worth a closer look. Start with one ad account and a date range. The tool reads from Meta and can save reports and exports on your machine.

## Install and try it

```bash
npx skills add Qwayk/safe-agent-skills@meta-ads-api-safe-cli -g -y
```

> Show me which Meta ad accounts I can read. Then check one week of spend, impressions, and clicks by campaign for the account I choose.

Use the [Quickstart](docs/quickstart.md) to install the CLI and run that report. The [setup guide](docs/onboarding.md) explains where to save the access token.

You can also compare two date ranges, inspect a creative, or save a [snapshot export](docs/snapshot_export.md) for deeper analysis. See the [command guide](docs/command_reference.md) for the exact options.
