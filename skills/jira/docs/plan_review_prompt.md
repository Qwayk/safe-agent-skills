# Review a Jira write plan

Ask your agent:

```text
Read this Jira plan file. Confirm the Jira site, fixed command, target path, query, body or upload hashes, risk level, and whether before-state can be saved. Explain the live Jira change in normal words. Do not apply it. Tell me the exact approval flags that would be required if I choose to continue.
```

If the plan content, body file, upload file, site, or target needs to change, create a new plan instead of editing the existing one.
