# Review a Jira apply receipt

Ask your agent:

```text
Read this Jira receipt and its run folder. Tell me whether Jira accepted the request, whether before-state was saved, whether verification succeeded, and what is still uncertain. Do not make another Jira change.
```

A receipt proves what this CLI attempted and recorded. It does not by itself prove that every Jira side effect completed, especially for asynchronous operations without a matching readback.
