# Fortnox docs

You do not need every page here on day one. The easiest path is to start with the real job: connect Fortnox, check the account, and ask the agent for the accounting, invoice, supplier, payroll, or stock work you actually need. These docs explain how to set up access, run safe first reads, review risky changes, and inspect proof without learning the whole Fortnox API first.
