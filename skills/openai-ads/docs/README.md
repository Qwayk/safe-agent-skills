# OpenAI Ads Docs

Start here when you want to know what to ask your agent, how to connect the tool, or what happens before an ad change goes live.

If you only want one safe first result, use the quickstart. It checks that the tool can reach your OpenAI Ads account without changing campaigns, ads, audiences, or tracking.

## Choose what you need

- [Get one safe first result](quickstart.md): connect the tool, check the ad account, list available tasks, and try one campaign read.
- [See real agent asks](use_cases.md): examples you can paste into an agent for reporting, troubleshooting, setup checks, and planned changes.
- [Understand approvals before changes](safety_model.md): what the agent can read by itself, what waits for your approval, and why spend or tracking changes need extra care.
- [Set up access](onboarding.md): create `.env`, add Ads Manager credentials, and understand what access has to come from OpenAI Ads Manager.
- [Fix connection problems](troubleshooting.md): common setup and auth problems.
- [Look up exact commands](command_reference.md): command syntax for reads, planned changes, measurement helpers, product-feed guidance, and targeting guidance.
- [Check API coverage](api_coverage.md): the official API boundary, operation count, and what is outside this tool.
- [See what was tested](proof.md): local tests, behavior checks, and the live-account limit.
- [Read wrapper guidance](skills_wrappers.md): when an agent should use this skill and when it should choose another tool.
- [See references](references.md): official OpenAI Ads docs used for the build.
- [Review configuration](configuration.md): local config options.
- [Review authentication](authentication.md): credential fields and auth behavior.

The short version: ask the agent to look first, explain what it found, and prepare any change for your approval before it touches live ads.
