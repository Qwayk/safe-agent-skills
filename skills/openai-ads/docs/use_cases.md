# Use Cases

Use this tool when you want an agent to help with real ChatGPT Ads account work: checking performance, finding setup problems, preparing new campaigns, reviewing audiences, or checking conversion tracking.

Start with reads. Once the agent explains what it found, you can decide whether to ask it for a planned change.

## Reporting and account checks

Ask:

- "Check yesterday's stats for this campaign and explain what changed."
- "List active and paused campaigns, then tell me which ones can serve."
- "Show account insights and call out campaigns that need attention."
- "Find ads or ad groups that look blocked, paused, archived, or missing setup."

## Campaign and ad work

Ask:

- "Create a new paused campaign draft for this service and show me the plan before anything goes live."
- "Prepare an ad group for San Francisco targeting, but do not activate it."
- "Update this ad's setup and wait for my approval before sending the change."
- "Pause this campaign only after showing me exactly what will change."

## Audiences, uploads, and files

Ask:

- "List custom audiences and tell me which ones are available for campaign work."
- "Prepare a custom audience upload plan, but do not upload anything yet."
- "Show me what image upload command would be used for this creative."

## Conversion tracking and measurement

Ask:

- "Tell me which conversion event fits a quote-request form."
- "Build an image tag for `order_created` and hide the Pixel ID in the output."
- "Check whether the tracking setup is missing anything important."
- "Prepare a server-side conversion event send in validate-only mode."

## Product-feed and targeting help

Ask:

- "Explain what product-feed campaign setup needs to happen in Ads Manager."
- "Find ad groups using product-feed setup and show their filters."
- "Look up location targeting options for San Francisco."

## Not a fit

Use another tool or do the work by hand for:

- Browser automation inside Ads Manager.
- Creating the product-feed connection or uploading a merchant catalog over SFTP.
- Normal OpenAI Platform work such as models, files, assistants, vector stores, batches, or fine-tuning.
- Any request that asks the agent to bypass this tool and make raw HTTP calls.
