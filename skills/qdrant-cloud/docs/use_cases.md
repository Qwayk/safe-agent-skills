# What to ask your agent

- **See what’s running.** “List my accounts and clusters. Show the region, size and Qdrant version for each cluster.”
- **Check recovery options.** “List this cluster’s backups and restore jobs. Show which backup I could use and how much newer data an in-place restore would replace.”
- **Review access.** “Show which members, roles and API keys have access to this account.”
- **Check costs and health.** “Show last month’s bill and this cluster’s recent usage, events and errors.”
- **Prepare a change.** “Estimate the price of this cluster size, then show me the exact change before sending it.”
