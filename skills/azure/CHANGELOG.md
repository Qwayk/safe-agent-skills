# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-06-28

### Added
- Azure-safe CLI with explicit command surface generated from official Azure REST specs.
- Generated inventory snapshot built from commit `ada8601c3b75c15f06f21e50f9368d9476229305`.
- Safe write flow that requires plan, apply, and explicit confirmation.
- Data-plane endpoint handling for data-plane operations.
- Documentation set rewritten for Azure-specific, source-ready public use.

### Changed
- Onboarding, quickstart, safety, references, troubleshooting, and proof pages to Azure-specific language.
- Tool-local guidance updated for this folder.

### Fixed
- Clarified refusal and acknowledgment gates for no-snapshot and irreversible operations in docs and safety guidance.

### Removed
- Initial public-facing docs were rewritten for Azure-specific content.
