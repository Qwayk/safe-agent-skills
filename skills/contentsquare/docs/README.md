# Contentsquare docs

For Contentsquare, start with the real job: confirm the OAuth connection, read one safe metric or export result, then decide whether a reviewed change plan is needed. These docs explain how to connect local Contentsquare access, ask useful first questions, understand approval rules, and check what has actually been verified.

Live Contentsquare account behavior still needs a separate safe-target run. Local tests and redacted examples are useful, but they are not live account proof.
