# What to ask Jobber

- “Which customers have open jobs and no recent activity?”
- “Which quotes are still waiting for a reply?”
- “Show upcoming visits and flag any gaps.”
- “Which invoices are still unpaid?”
- “Show me the jobs linked to this client.”
- “Prepare a plan to update this client. Stop before applying it.”
- “Show the webhook topics for job updates and check this sample signature.”

Start by [checking the account](quickstart.md). Ask for a [plan and receipt](safety_model.md) when the job needs a change. Access depends on the app, account permissions and the records Jobber makes available.
