# Instagram

Ask your agent to show your latest posts and comments, explain how a post performed, or prepare an image, Reel, or carousel for you to review. The tool uses Instagram Login for professional accounts.

The agent checks which account is connected before reading your posts. If you ask it to publish, it shows you the account, caption and media first. Instagram prepares the media before publishing it, so you can review each step.

Install the `instagram-safe-cli` skill from `Qwayk/safe-agent-skills`, or run this command.

```bash
npx skills add Qwayk/safe-agent-skills@instagram-safe-cli -g -y
```
