# What you can do with Awin Publisher

Start by asking which publisher accounts your token can see. Name the publisher account for the rest of the work.

- “List my joined and pending programs, and show which ones I can use now.”
- “Show me last week’s transactions by advertiser and approval status.”
- “Find available offers for this advertiser.”
- “Generate tracking links for these pages. Tell me which publisher and advertiser IDs you used.”
- “Download the enhanced feed for this advertiser and locale. Keep the current file if the download fails.”
- “Prepare an order submission from this file. Show me the publisher, advertiser, and orders, then wait for approval.”

Ask the agent to give you a short summary, the account it used, and any file paths you need. [Start with an account check](quickstart.md) · [Find commands](command_reference.md)
