# Use cases

Use these as plain user asks before you choose flags.

## Good first asks

- "Show me GiantPanda domain stats from 2026-08-01 to 2026-08-07."
- "Get the next page of domain stats for this period."
- "Compare one week and the previous week and call out any spike."
- "Prepare a local plan to add `example.com` and `shop.example.com`."

## Common day-to-day asks

- See clicks, requests, and revenue trend by date window.
- Pull larger windows to spot spikes or missing days.
- Add domains in a controlled batch after review.
- Stop before anything live and inspect the written plan.

## Useful outputs to expect

- Reads: date-window stats plus paging details from the API host.
- Plan: private dry-run plan file with `max_domains`, duplicate handling, and exact operation metadata.
- Apply: receipt with provider response and verification status.
