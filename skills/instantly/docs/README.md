# Instantly docs

Instantly is easiest to use when you start with the real job, then check setup, safety, and proof before asking an agent to do more. These docs explain how to review campaigns, leads, accounts, replies, and outreach performance, what access is needed, and where the tool stops before risky changes.

If you are new, read the first few links before asking for account data or changes. They explain the useful jobs, the setup path, and the safety limits.
