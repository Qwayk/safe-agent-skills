# YouTubeVideoUploadService (Google Ads API v25)

Command shape:
- `google-ads-api-tool you-tube-video-upload-service <method-kebab> --in request.json`

Notes:
- Requests are JSON objects matching the selected RPC request message. Unknown fields are rejected.
- Write methods are plan-first. Live apply requires the allowlist and applicable risk approvals; unsupported snapshot shapes remain blocked unless explicitly supported.

## Methods
- `create-you-tube-video-upload` — `YouTubeVideoUploadService.CreateYouTubeVideoUpload` (write; plan-first; unary_unary) — request: `CreateYouTubeVideoUploadRequest` → response: `CreateYouTubeVideoUploadResponse`
- `remove-you-tube-video-upload` — `YouTubeVideoUploadService.RemoveYouTubeVideoUpload` (write; plan-first; unary_unary) — request: `RemoveYouTubeVideoUploadRequest` → response: `RemoveYouTubeVideoUploadResponse`
- `update-you-tube-video-upload` — `YouTubeVideoUploadService.UpdateYouTubeVideoUpload` (write; plan-first; unary_unary) — request: `UpdateYouTubeVideoUploadRequest` → response: `UpdateYouTubeVideoUploadResponse`
