# NameBright

Use NameBright to check which domains you own, see renewal dates, and review your DNS records. You can also check whether a name is available or see which domains are waiting to move between NameBright accounts.

Try asking your agent, “List my first five domains,” or “Check the nameservers for example.com.” The agent reads the account first. If you ask it to buy, renew, or move a domain, it saves a plan and shows what needs your approval before it sends the request.

## Get started

Ask your agent to install the `namebright` skill from Qwayk, or run:

```bash
npx skills add Qwayk/safe-agent-skills@namebright -g -y
```
