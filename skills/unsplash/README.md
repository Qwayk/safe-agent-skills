# Unsplash

Find photos for an article or campaign, compare work from different photographers, or build a set of images that fit together. The tool can search photos, collections, topics, and profiles and save results in a local JSON file for review.

Ask your agent to find 20 photos for a home office article and show the best five with preview links, photo IDs, and photographer credits.

When you choose a photo, ask for a saved download preview. Review the photo and where it will go. Unsplash records the download when you approve and apply that preview. You can also ask it to save a local copy.

## Install

Ask your agent to install `unsplash` from `Qwayk/safe-agent-skills`, or run the command below.

```bash
npx skills add Qwayk/safe-agent-skills@unsplash -g -y
```
