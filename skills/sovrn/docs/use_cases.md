# What you can ask about Sovrn

## Check a product link

> Can this product link earn through Sovrn for my site in the US?

Use the site's Commerce API key. A positive result applies to the site and country you checked. You can use both Commerce keys to compare prices or check for coupons when your account has access.

## Find which pages are earning

> Which buying guides earned the most last week? Show the dates and the main pages.

Use the Commerce secret key for the site you want. Ask for the report dates and filters along with the result. You can also check earnings by link, merchant, or transaction.

## Look up approved merchants

> Which approved merchants in this campaign sell clothing?

Use the Commerce secret key and a campaign ID. Ask for all the matching pages if you need the full list. The tool returns one page per request.

## Look at ad revenue

> Which sources brought in the most ad revenue yesterday?

Use the Advertising key and publisher ID. Ask for the account, dates, and breakdown in the answer. Save the report privately if you need the details later.
