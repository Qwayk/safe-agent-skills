# Open Library

Find books, authors and editions in the public Open Library catalog. Look up an ISBN to see which edition it belongs to, or open an author's record to find more of their work.

Try asking “Find three books about Dune and open the best match.” Start with a small search, then check the author or edition before using the result. Public lookups work without an account or API key.

## Install the skill

```bash
npx skills add Qwayk/safe-agent-skills@open-library -g -y
```

If the skill does not appear right away, reopen Codex. [Install the command-line tool and run your first search](docs/quickstart.md).
