# Jobs and batches

Open Library work should stay small and respectful of the public API. This release is read-only and does not include batch jobs or write actions.

For repeatable research, run the explicit search, book, or subject commands one request at a time and keep limits low. That makes the result easier to review and avoids treating Open Library like a bulk-harvest source.

Use `docs/command_reference.md` for the supported command list.
