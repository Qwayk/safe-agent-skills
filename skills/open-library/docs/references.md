# References

These are the official Open Library references used for book search, book lookup, subjects, and privacy expectations.

- https://openlibrary.org/developers/api
- https://openlibrary.org/dev/docs/api/search
- https://openlibrary.org/dev/docs/api/books
- https://openlibrary.org/dev/docs/api/subjects
- https://openlibrary.org/help/faq/privacy

Notes for this tool (2026-05-21):

- The Open Library commands use public, low-volume read endpoints.
- No authentication is required.
- Keep list-style calls limited (`--limit`, `--offset`) and avoid bulk harvests.

For normal work, start with a small search or lookup, then use these links only when you need to confirm how Open Library names fields or limits public requests.
