# TheMealDB

Find meal ideas by name, ingredient, category or cuisine. Ask “Find three meals with chicken breast and open one recipe.” The tool gets the recipe's ingredients, measures and instructions from TheMealDB.

The built-in key works for development and education without an account or settings file. TheMealDB requires a paid subscription for app-store releases. [API guide](https://www.themealdb.com/api.php) · [Terms of use](https://www.themealdb.com/terms_of_use.php)

## Install the skill

```bash
npx skills add Qwayk/safe-agent-skills@themealdb-safe-reader -g -y
```

If the skill does not appear right away, reopen Codex. [Install the command-line tool and run your first recipe search](docs/quickstart.md).
